## Project Description
QuickChat is a Java console application that provides user registration 
and login functionality. This is Part 1 of the PROG5121 Portfolio of Evidence.

## Features
- Username validation (underscore and max 5 characters)
- Password complexity validation
- Cell phone number validation with international code
- User login with authentication
